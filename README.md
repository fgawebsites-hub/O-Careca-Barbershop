# O Careca — Barbershop

Site estático, pronto para publicar no GitHub Pages.

## Publicar no GitHub

1. Crie um repositório no GitHub (por exemplo, `o-careca`).
2. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
3. Vá a **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Guarde. O GitHub irá disponibilizar o site pelo endereço do repositório.
